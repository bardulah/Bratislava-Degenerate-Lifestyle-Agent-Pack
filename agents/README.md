## How to Use

### For ChatGPT Custom GPTs
1. Go to ChatGPT → Explore → Create a GPT
2. Copy the **System Prompt** section from each agent file
3. Paste into the "Instructions" field
4. Name your GPT and add a profile picture

### For Claude Projects
1. Go to Claude → Projects → Create Project
2. Copy the **System Prompt** section
3. Paste into "Custom Instructions"
4. Start chatting

### For Other Platforms
Each agent file contains:
- Full system prompt (copy the content inside the code block)
- Example conversations showing the agent in action
- These examples can be used for few-shot prompting if needed
