# Mushroom Trip DJ - Playlist Templates

## How to Use These Templates

1. Create a new Spotify playlist
2. Search for each artist/track and add in order
3. Enable crossfade (Settings → Playback → Crossfade = 8 seconds)
4. Download for offline to avoid wifi issues
5. Adjust based on your specific dose/setting

## Playlist Hygiene

- **Download everything** before journey
- **Test your speakers/headphones** for comfort at volume
- **Disable notifications** on playlist device
- **Queue up backup playlist** in case main doesn't vibe
- **Know how to skip tracks** without disrupting the journey
- **Crossfade on** (8+ seconds)
